Resumen Explicativo y Notas Docentes por Ejercicio

Formulario Oficial Permitido

1. Tamaño de paso uniforme

h = (b − a) / n

Donde n es el número de subintervalos y existen n + 1 nodos equiespaciados x₀, x₁, ..., xₙ.

2. Regla del Trapecio Compuesto (Cualquier n ≥ 1)

T = h · [ (f₀ + fₙ)/2 + Σ(i=1 a n−1) fᵢ ]

También expresado como: T = (h/2) · [ f₀ + 2f₁ + 2f₂ + ... + 2fₙ₋₁ + fₙ ].

3. Regla de Simpson 1/3 Compuesta (Requiere n PAR)

S₁/₃ = (h / 3) · [ f₀ + fₙ + 4 · Σ(i impar) fᵢ + 2 · Σ(i par interior) fᵢ ]

Patrón de pesos: [1, 4, 2, 4, 2, ..., 4, 1] multiplicados por h/3.

4. Regla de Simpson 3/8 Compuesta (Requiere n múltiplo de 3)

S₃/₈ = (3h / 8) · [ f₀ + fₙ + 3 · Σ(i no músc. de 3) fᵢ + 2 · Σ(i músc. de 3 interior) fᵢ ]

Patrón de pesos para n=3: [1, 3, 3, 1] multiplicados por 3h/8.

5. Combinación de Métodos y Cálculo de Errores

Eₐ = |I_ref − I_aprox|   |   E_% = 100 · (Eₐ / |I_ref|)

• Con 7 subintervalos (Ej. 19 y 20): se combina Simpson 1/3 en los primeros 4 subintervalos [x₀, x₄] y Simpson 3/8 en los últimos 3 subintervalos [x₄, x₇].
• Con 9 subintervalos (Ej. 21): se puede combinar Simpson 1/3 en 8 subintervalos más Trapecio en el noveno, o aplicar Simpson 3/8 puro al ser 9 múltiplo de 3.
